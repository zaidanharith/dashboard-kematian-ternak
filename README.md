# Dashboard Kematian Ternak

Dashboard untuk memantau data kematian ternak.

## Struktur Proyek

- `frontend/` — Next.js (App Router, TypeScript, Tailwind CSS)
- `backend/` — Express.js + Prisma

## Menjalankan Proyek

Install dependencies di root, frontend, dan backend:

```bash
npm install
cd frontend && npm install
cd ../backend && npm install
```

Jalankan frontend dan backend sekaligus dari root:

```bash
npm run dev
```
